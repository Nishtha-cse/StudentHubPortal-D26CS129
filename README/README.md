 StudentHub Portal

 User Roles

| Role | Description |
| --- | --- |
| Student | Registers, logs in, views/manages profile, browses events |
| Admin | Manages students, events, and portal content via dashboard |
| Guest | Views public pages (Home, About, Contact, FAQ) before login |

Key Modules

- Authentication (Registration / Login / Logout)
- Student Dashboard & Profile Management
- Event Management (Browse, Register, Feedback)
- Admin Dashboard (Role-based access & content control)
- Static Informational Pages (About, Contact, FAQ)

Sitemap (Minimum 10 Pages)

```
StudentHub
├── Home
├── About
├── Register
├── Login
├── Dashboard (Student)
├── Events
├── Profile
├── Contact
├── Admin (Dashboard)
├── FAQ
└── Feedback
```

 Navigation Flow

```
Guest → Home → (Login / Register)
Student → Login → Dashboard → Profile / Events / Feedback
Admin   → Login → Admin Dashboard → Manage Students / Manage Events
All Users → Home → About / Contact / FAQ (public access)
```
